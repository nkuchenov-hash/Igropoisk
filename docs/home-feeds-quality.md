# Качество «Сейчас популярно» и релизов главной

## Граница

Полный календарь релизов остаётся полным источником данных. Правила качества влияют только на компактную ленту главной. Они не создают страницы игр, не меняют даты редактора и не используют OpenAI.

## «Сейчас популярно»

Позиция допускается, когда есть текущий всплеск, подтверждённый независимыми сигналами: минимум двумя группами сообщества, минимум двумя независимыми новостными источниками либо несколькими свежими подтверждениями одной сильной группы. Один только Steam Top Sellers считается слабым коммерческим сигналом и не является достаточным основанием. Разные издания одной игры объединяются по каноническому названию.

При количестве менее 20 качественных позиций публикация блокируется, а production сохраняет предыдущий проверенный snapshot. Данные считаются устаревшими через 12 часов.

## Релизы

Технические продукты определяются только объективными маркерами названия: demo, prologue, playtest, benchmark, soundtrack, dedicated server, SDK, editor, toolkit и аналогичные обозначения. Субъективные оценки качества игры не применяются.

Каждая запись получает объяснимый score: текущая популярность, присутствие в каталоге, редакционная готовность, число источников, точность даты и проверенная обложка. На главную выбирается не более 12 записей. Дубли и альтернативные издания не удаляются из календаря, а только не выбираются повторно для главной.

Категории: `recent`, `soon`, `upcoming`, `tbd`, `expired`.

## Контроль

`data/home-feeds-health.json` и `/admin/home-feeds-health/` работают только на чтение. Экран показывает причину каждой позиции popular, выбранные релизы, исключения, дубли и живую проверку возраста данных.
