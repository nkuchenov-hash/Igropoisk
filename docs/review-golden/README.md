# Игропоиск — Golden Review Set v1

**Статус:** EDITORIAL REFERENCE SET  
**Зафиксировано:** 2026-09-04

Этот каталог хранит человеческие эталонные обзоры для Review Skill v1. Они нужны для проверки качества моделей и для сохранения редакционного стандарта Игропоиска.

## Главное правило

Эти тексты — ориентиры качества, структуры, естественности языка и глубины анализа. Они **не являются шаблонами предложений** и не должны копироваться моделью по фразам или одинаковой структуре.

Фактический источник истины для нового обзора — канонический `data/game-sources/<slug>.json` конкретной игры. Golden Review Set не заменяет source corpus и не разрешает переносить факты из одной игры в другую.

## Набор v1

1. `mafia-the-city-of-lost-heaven.md` — **primary golden**. Основной эталон журнальной прозы, структуры и финального послевкусия.
2. `dangerous-dave-in-the-haunted-mansion.md` — компактная старая игра с механически насыщенным анализом.
3. `far-cry.md` — шутер с открытыми пространствами, AI, тактикой и конкретными проблемами без ритуального блока «что устарело».
4. `jack-orlando.md` — квест, где важны расследование, художественная постановка, пиксель-хантинг и логика загадок.
5. `mass-effect.md` — RPG с миром, персонажами, выборами, боем, интерфейсом и исследованием.
6. `wolfenstein-3d.md` — ранний FPS с темпом, лабиринтами, секретами, HUD и ограничениями дизайна без привязки к текущему году.
7. `need-for-speed-hot-pursuit-2010.md` — аркадная гонка, где механика Autolog описывается в настоящем времени, а историческая новизна — отдельно как контекст выхода.

## Что проверять по этим эталонам

- статья основана на evidence, а не на общей памяти модели;
- версия игры не смешана с ремастерами, ремейками, портами и сиквелами;
- структура возникает из самой игры;
- заголовки позволяют понять маршрут статьи по одному оглавлению;
- полноценные абзацы вместо цепочки коротких строк;
- конкретные механики и запоминающиеся детали вместо универсальной похвалы;
- HUD, интерфейс, навигация и feedback не игнорируются, если они содержательно важны;
- недостатки называются напрямую и обсуждаются в контексте соответствующей системы;
- нет обязательного раздела «что устарело»;
- текущий год не используется как точка отсчёта;
- механики по умолчанию описываются в настоящем времени;
- исторический контекст используется только когда помогает понять игру;
- финал формулирует характер игры и оставляет самостоятельную мысль, а не повторяет список плюсов и минусов.

## Архитектурная граница

Golden Review Set принадлежит Review Module и не меняет Game Page Module. Наличие или отсутствие golden/reference-текста или собственного обзора Игропоиска не блокирует создание и публикацию страницы игры.

Основной контракт: `docs/REVIEW_MODULE_WORKING.md`.  
Редакционная политика: `config/review-editorial-policy.json`.
