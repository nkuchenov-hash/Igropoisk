# Игропоиск — Game Page Editorial Skills v3

**Статус:** READY FOR PAGE MODEL BENCHMARK  
**Зафиксировано:** 2026-09-07

## Три page-skills, одна Page Model

Subtitle, Description и Features остаются отдельными skills, потому что у них разные задачи, форматы и QC:

- `config/parsers/game-page-subtitle-skill.json`
- `config/parsers/game-page-description-skill.json`
- `config/parsers/game-page-features-skill.json`

Но для одной конкретной страницы они не выбирают разные модели.

Перед Page Editorial Job назначается один `page_model_id`. Эта модель делает Subtitle + Description + Features до полной готовности Page Editorial Bundle.

Разные игры могут получать разные Page Models.

## Общий источник истины

Все page-skills используют только канонический корпус Game Page Module:

- `data/game-sources/<slug>.json`;
- `data/game-source-content/<slug>.json`;
- Game Registry / `game_id`.

Skills не ищут источники самостоятельно и не используют модельную память вместо evidence corpus.

Benchmark-only truncation до первых N источников/символов запрещён. Если корпус велик, та же Page Model обрабатывает все source-aware chunks с зафиксированным 100% coverage.

## Page model affinity

Допустимо:

```text
Game A → Model X → Subtitle + Description + Features
Game B → Model Y → Subtitle + Description + Features
```

Недопустимо:

```text
Game A Subtitle → Model X
Game A Description → Model Y
Game A Features → Model Z
```

Если Model X окончательно не справилась, её частичный job не смешивается с другой моделью. Новый кандидат начинает новый полный page-copy job с нуля.

## Skill 1 — Subtitle

### Задача

Короткий узнаваемый портрет игры, а не жанровая подпись и не мини-Description.

Выбирается минимальный набор identity-bearing признаков, без которого образ игры становится неправильным или слишком общим.

Не существует обязательной формулы `сеттинг + враг + механика`.

Примеры принципа:

- Spore: `От клетки до космической цивилизации` уже задаёт почти весь уникальный образ.
- Dangerous Dave нельзя свести только к отдаче дробовика: без особняка и монстров портрет искажён.
- Far Cry нельзя свести только к тропическим перестрелкам: важны наёмники/мутанты и свобода подхода.

### Формат

Обычно 7–15 слов, мягкий максимум 18, одна строка.

Главный тест: после удаления названия игры subtitle не должен подходить десяткам неродственных игр.

## Skill 2 — Description

### Задача

Полноценное вводное описание: что это за игра, кем является игрок, чего он добивается, что регулярно делает и какие системы определяют опыт.

### Формат

Ориентир 130–190 русских слов, мягкий максимум 220, 1–3 абзаца без bullets.

Description должен отвечать минимум на четыре вопроса:

1. Какова исходная ситуация?
2. Кто игрок и какова его цель?
3. Что игрок регулярно делает?
4. Какие конкретные системы/детали отличают игру от обычного представителя жанра?

Это не рецензия и не рекламный текст.

## Skill 3 — Features

### Задача

4–6 коротких сканируемых тезисов о характерных особенностях игры.

Обычно 2–7 слов на пункт, мягкий максимум 10. Не полноценные предложения, без точки в конце.

Хорошо:

- `Дробовик с физической отдачей`
- `Полиция и дорожные правила`
- `Выборы Paragon и Renegade`
- `Пять стадий развития`

Плохо:

- `Захватывающий сюжет`
- `Красивая графика`
- длинное предложение вместо тезиса.

## Общие правила качества

Для всех трёх skills:

- точная версия игры обязательна;
- факты только из канонического корпуса;
- механики — в настоящем времени;
- evergreen-подача;
- без `по данным источников`, `корпус показывает`, `модель обнаружила`;
- без выдуманных деталей;
- конкретика важнее общих прилагательных;
- corpus определяет evidence, но не риторическую структуру;
- technical/QC retry сначала выполняет та же Page Model;
- другая модель не может продолжить незавершённый Page Editorial Job.

## Review Skill — отдельный выбор модели

Review Module использует тот же канонический Evidence Package, но **не наследует `page_model_id`**.

Для обзора создаётся отдельный Review Editorial Job с собственным `review_model_id`. Одна Review Model выполняет обзор end-to-end, но она может отличаться от Page Model этой же игры.

Например:

```text
Mafia Page   → Model A
Mafia Review → Model D
```

Это допустимо и не требует пересборки страницы.

Страница не ждёт Review: отсутствие/ошибка обзора не блокирует Game Page publication.
