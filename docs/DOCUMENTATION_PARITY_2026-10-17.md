# Игропоиск — проверка документации и кода (2026-10-17)

## Проверенный срез
Основная ветка `main`, коммит `2f2b5d7fa9`. Это статическая проверка структуры, некоторых исходников и документов; пайплайны, парсеры и production-публикация не запускались.

## Что подтверждено
- `docs/PROJECT_ROADMAP.md` — единый верхнеуровневый план; `docs/SYSTEM_ARCHITECTURE.md` — архитектура; `PROJECT_RULES.md` — продуктовые требования.
- `features/MODULE_RULES.md` определяет регистрируемые модули, обязательный `module.json`, `RULES.md` и центральные UI-компоненты.
- `assets/design-system.css` существует и используется как каноническая основа дизайн-системы.
- `services/content-api/src/server.mjs` реализует отдельный News Content API, HTTP health/read endpoints, разрешённые CORS origins и runtime modes; не путать этот действующий сервис с целевой архитектурой всего продукта.
- В репозитории присутствуют многочисленные модули, наборы данных, тесты и **52** GitHub Actions workflow. Количество workflow не означает, что каждый нужен или что все успешно выполняются.

## Безопасные действия
1. Добавить единый AI-entrypoint `AGENTS.md` **как маршрутизатор к существующим каноническим документам**, а не как конкурирующий roadmap.
2. Отдельно проверить зарегистрированные `features/*` против `config/feature-modules.json` и реально используемые CSS-компоненты против `config/design-system-components.json`. Ничего не удалять без анализа импортов/публикации.
3. Инвентаризировать 52 workflow: триггер, точка записи, пересечение с другими workflow, production permission, статус последнего реального запуска. До такой проверки не отключать и не удалять workflow.
4. Верифицировать, что будущая PostgreSQL/VPS/Object Storage архитектура помечена как цель, а не уже завершённая миграция.
5. Для каждого изменения module/CI/contracts — адресные тесты, publish gate, staging, лишь затем production.

## Не подтверждено этим аудитом
Фактические результаты GitHub Actions, данные production storage, валидность всех публикаций, покрытие тестами, соответствие содержимого всех тысяч файлов. Не заявлять о полном parity без запуска локальных проверок.
