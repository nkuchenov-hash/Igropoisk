# Популярное и релизы на главной

## Публикационный контракт

- «Сейчас популярно» публикует не менее 20 уникальных игр, отсортированных по рассчитанному индексу. У каждой позиции должны быть подтверждающие сигналы и пригодная обложка.
- «Новые и ожидаемые релизы» сначала показывает релизы за последние 7 дней, затем будущие события по ближайшей известной дате. События без точной даты идут после датированных.
- Источники данных обновляются обычными парсерами. OpenAI API для этих блоков не используется.
- Ошибка одного парсера не должна останавливать другой. Непроверенные или неполные snapshots не публикуются.
- После обновления production проходят статическая проверка данных и браузерная проверка обоих блоков.

## Текущее покрытие

Popular использует доступные сигналы игровых СМИ, Steam и YouTube; Reddit и Twitch могут быть недоступны без авторизации. Релизный parser использует Steam как основной официальный источник и дополняет совпавшие записи RAWG при наличии `RAWG_API_KEY`.
