# Game Page module acceptance

A Game Page is publishable only when the universal Game Page module completes the same bounded cycle for a requested canonical game identity without hand-written per-game code or data.

The module must:

1. resolve and persist the canonical game identity;
2. collect structured page data and verified media;
3. complete professional-source discovery and preserve the canonical source corpus;
4. calculate the Игропоиск rating from every discovered verified professional score that qualifies under the rating rules;
5. never block page publication merely because an arbitrary minimum number of professional reviews or ratings was not reached; additional source coverage may continue as later enrichment;
6. build the internal Audience Profile from available evidence; missing or broken audience evidence must fall back to the neutral Игропоиск profile and must not block publication;
7. produce Russian page editorial only from verified page facts; the AI model/provider is a replaceable editorial backend and no specific provider, model, benchmark winner or Spore prose-quality result is a structural Game Page module gate;
8. pass the universal content, media and shell quality gates;
9. materialize one immutable canonical green page package;
10. publish that exact green package through the normal staging and production path;
11. verify the resulting live page without per-game runtime exceptions.

Audience Profile is an internal game-level asset. It may influence register, terminology, rhythm and emphasis, but it is never a public page block and it may never invent demographic certainty. Aggregate demographics are accepted only from an explicit attributable aggregate source.

The Review subsystem remains separate. A review may be embedded in a Game Page when one exists, but review generation, review length and review-corpus targets are not owned by the Game Page module and never determine whether the base game page can exist.

`spore` is a structural acceptance fixture only: it proves that the shared module can move a real game through the universal path. The literary quality of its current generated copy and the model used to generate that copy are tested separately from module readiness.

News, Popular Now, Top-250, Releases and Search are external consumers/triggers and are not parts of the Game Page module.
