# Игропоиск — дизайн-система страницы игры

## Обязательная структура

Все страницы `game/*/index.html` подключают один общий шаблон и не содержат собственного визуального оформления.

1. **Header** — логотип, «Главное», «Поиск игр», «Новости», поиск и тема.
2. **Hero** — фоновый арт, хлебные крошки, название, год, жанры, разработчик.
3. **Действия** — «В избранное», «Хочу сыграть», «Оценить игру».
4. **Рейтинги** — данные рейтингов подключаются из соответствующих систем. Личная оценка хранится отдельно и не подменяет общий рейтинг.
5. **Медиалента** — только реальные изображения и видео из источников или магазина. Нарисованные заглушки не считаются медиаматериалом.
6. **Вкладки** — «Об игре», «Обзоры», «Медиа», «Новости», «Системные требования», «Гайды», «Источники».
7. **Об игре** — описание, ключевые особенности, фактическая информация, оценки, официальные ссылки и похожие игры.
8. **Обзоры** — это интеграционный блок страницы, а не часть модуля создания страницы. Если редакционный обзор Игропоиска существует, он показывается первым. Внешние карточки создаются только из реально найденных публикаций и ведут на оригинал. Отсутствие обзора не блокирует создание и публикацию страницы игры.
9. **Системные требования** — здесь же показываются платформы. Отдельные разделы «Режимы игры» и «Достижения» не используются.

## Граница модулей

Модуль страницы отвечает за расположение и отображение блока «Обзоры», но не за поиск рецензий, написание редакционного обзора или review-QC. Эти данные приходят из отдельной review/editorial-подсистемы и связываются со страницей через каноническую игру/Game Registry.

Та же модель применяется к новостям, гайдам и другим связанным материалам: страница умеет их показывать, но их создание относится к соответствующим независимым модулям.

## Награды

Награды не являются декоративным UI-компонентом.

- Не используются золотые цвета, кубки, медали, лавровые венки и нарисованные бейджи.
- Нельзя вручную придумывать формулировки вида «игра года» или «выбор редакции» как награду.
- Блок скрыт, пока нет спарсенных записей.
- Каждая запись обязана содержать `name` и `source_url`.
- Допустимы только логотипы или изображения, полученные из исходного сайта. Генерировать графику награды нельзя.
- В интерфейсе награда отображается нейтральной строкой: название, категория, год, источник и ссылка.

## Данные

Основные факты хранятся в `data/game-content/*.json`. Медиа, публикации и ссылки могут дополняться из `data/drafts/*.json`, только если совпадает реальная игра, а не только исходный поисковый запрос.

Обзоры и их собственные рабочие данные не считаются частью канонического набора данных модуля страницы. Страница только читает опубликованные связанные материалы.

Награды импортируются командой:

```bash
node scripts/parse-awards.mjs <slug> [title]
```

Результат сохраняется в `data/awards/<slug>.json`. Общий рендерер отбрасывает записи без ссылки на источник.

## Запрещено

- отдельный CSS или новый визуальный стиль для конкретной игры;
- пустые декоративные вкладки;
- считать отсутствие обзора причиной не создавать страницу игры;
- генерировать обзор внутри page-builder;
- рекламные псевдообзоры без исходной публикации;
- дублирование платформ в hero и отдельном блоке — платформы находятся в системных требованиях;
- отображение достижений и игровых режимов как самостоятельных вкладок;
- синтетические или нарисованные награды.
