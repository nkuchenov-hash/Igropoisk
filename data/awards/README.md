# Награды игр

Эта папка предназначена только для результатов парсинга внешних источников.

Файл игры: `data/awards/<slug>.json`.

```json
{
  "game_slug": "elden-ring",
  "checked_at": "2026-08-03T00:00:00Z",
  "awards": [
    {
      "name": "Название награды или номинации",
      "category": "Категория",
      "year": "2022",
      "source_name": "Название сайта-источника",
      "source_url": "https://source.example/award-page",
      "image_url": "https://source.example/original-logo.png"
    }
  ]
}
```

Обязательны `name` и `source_url`. `image_url` разрешён только для оригинального изображения, полученного из источника. Самодельные лавры, кубки, медали, иконки и декоративные значки запрещены. При отсутствии валидного файла блок наград на странице игры не отображается.
