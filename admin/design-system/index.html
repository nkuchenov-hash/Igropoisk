Правила использования

1. Сначала обновляется эта дизайн-система. 2. Затем компоненты подключаются к страницам. 3. Контент не должен приносить новые цвета, радиусы, тени или типографику. 4. Главная, поиск, новости, игровые страницы и админка используют одну систему токенов.
