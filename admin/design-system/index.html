Правила использования

1. Сначала компонент утверждается здесь. 2. Затем он подключается к действующим страницам. 3. Результат поиска обязательно содержит описание сути игры максимум в двух предложениях. 4. Новостная карточка обязательно содержит дату и краткое описание. 5. Нельзя создавать отдельный визуальный стиль для новой игры или раздела.
