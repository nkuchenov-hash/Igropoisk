Обязательные правила

Скриншоты прокручиваются горизонтально и меняют hero по нажатию. Обзоры других изданий не смешиваются с обзором Игропоиска. Рейтинг Игропоиска выводится только из журнала парсера. Пользовательская оценка хранится в серверной базе, а не в localStorage. Любое новое визуальное решение сначала добавляется в этот модуль.
