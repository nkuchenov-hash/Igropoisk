# Игропоиск — обязательные правила

## Абсолютный запрет пустых страниц

Публикация пустой, частично заполненной, временной или «догружающейся» страницы игры запрещена. Игра не появляется на главной, в каталоге, поиске, подборках, sitemap или по публичному маршруту, пока не прошла publish gate.

Запрещены фразы «информация загружается», «материалы пока не найдены», пустые вкладки, фиктивные карточки и подставные тексты. Неполные записи существуют только во внутренней очереди со статусом `draft`, `collecting`, `review` или `rejected`.

## Publish gate

Статус `published` разрешён только при одновременном выполнении требований:

1. Идентичность подтверждена официальным источником и крупной базой либо двумя независимыми базами.
2. Проанализировано 10–20 реальных источников.
3. Использованы доступные официальные страницы игры, разработчика и издателя.
4. Заполнены название, дата/статус релиза, жанры, платформы, разработчик и издатель.
5. Есть краткое описание и отдельный интегрированный обзор.
6. Есть сюжет, структура кампании либо объяснение отсутствия сюжетной кампании.
7. Есть минимум 4 содержательные особенности.
8. Есть hero, обложка и минимум 6 реальных скриншотов.
9. Есть минимум одно официальное видео, если оно существует.
10. Рассчитан рейтинг Игропоиска либо зафиксирована недостаточность данных.
11. Каждая публичная вкладка содержит реальные материалы; пустая вкладка не создаётся.
12. Для текста сохранены URL, название источника, дата публикации, дата проверки и доверие.
13. Автоматическая проверка полноты завершилась без ошибок.
14. Запись прошла редакционную или формальную автоматическую проверку качества.

Если хотя бы одно условие не выполнено, страница не публикуется вообще.

## Рейтинги

На сайте только два рейтинга:

- рейтинг Игропоиска по шкале 0–10;
- рейтинг пользователей Игропоиска.

Отдельного рейтинга «критики» нет. Пользовательский рейтинг полностью скрывается, пока нет ни одного голоса. Ноль и пустая карточка запрещены.

## Страница игры

Hero — слайдер из официального key art/header и 4–6 реальных скриншотов. Фон переключается автоматически примерно раз в 5–6 секунд и вручную.

Возможные вкладки: «Всё об игре», «Медиа», «Статьи», «Обзоры», «Гайды», «Советы», «Новости». Вкладка создаётся только при наличии содержимого.

«Всё об игре» обязательно содержит описание, интегрированный текст, сюжет/структуру кампании, особенности, дату выхода, жанры, платформы, разработчика, издателя, скриншоты и раскрываемый список источников.

«Медиа» содержит отдельные блоки скриншотов и официальных видео.

## Фреймворк 10–20 источников

Собственный текст Игропоиска не является пересказом одного сайта. Для каждой страницы или статьи анализируются 10–20 источников.

Приоритет:

1. официальный сайт игры;
2. сайт разработчика;
3. сайт издателя;
4. Steam, PlayStation, Xbox, Nintendo, Epic Games Store, GOG;
5. IGDB, RAWG, Metacritic, OpenCritic;
6. IGN, GameSpot, PC Gamer, Eurogamer, Rock Paper Shotgun, GamesRadar+, Polygon;
7. Игромания, StopGame, GameMAG и проверяемые редакционные материалы DTF.

Официальные источники имеют приоритет для дат, платформ, компаний и состава изданий. Оценочные суждения подтверждаются несколькими независимыми публикациями. Чужие статьи не копируются. Для каждого факта сохраняются доказательства источника.

## Структура данных

Каждая игра содержит блоки `publication`, `identity`, `release`, `companies`, `classification`, `editorial`, `media`, `ratings`, `materials`, `sources`.

Публичный JSON содержит только записи со статусом `published` и `gate_passed: true`. Фронтенд повторно проверяет publish gate. Сборка завершается ошибкой при обнаружении хотя бы одной неполной публичной записи.

## Развитие проекта

Существующий каркас улучшается, а не заменяется новым прототипом. Маршруты, вкладки, модель данных, два рейтинга и publish gate являются постоянной основой проекта.
