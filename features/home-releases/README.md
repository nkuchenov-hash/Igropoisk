# Ближайшие релизы на главной

Независимый инструмент правой части объединённого блока главной страницы.

- Интерфейс: `assets/home-releases/`
- Правила: `features/home-releases/rules.json`
- Источник: `data/releases/current.json`
- Админка: `admin/home-widgets/releases/`
- Публичный календарь: `calendar/`

Инструмент не меняет данные календаря. Он только выбирает ближайшие события, сортирует их по дате и показывает горизонтальную ленту.
