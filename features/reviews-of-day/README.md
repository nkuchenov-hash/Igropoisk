# Обзоры дня

Независимый редакционный инструмент левой части объединённого блока главной страницы.

- Интерфейс: `assets/reviews-of-day/`
- Правила выбора: `features/reviews-of-day/rules.json`
- Манифест опубликованных обзоров: `data/home-widgets/reviews-of-day.json`
- Админка: `admin/home-widgets/reviews-of-day/`
- Источники статей: `data/articles/{slug}.json`

В выборку нельзя добавлять черновики, статьи без обложки и материалы, не прошедшие обязательный source gate. Выбор главной карточки взвешенный и обновляется по временным слотам.
