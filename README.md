# Игропоиск

Отдельный репозиторий проекта «Игропоиск».

Публичный каталог использует строгий publish gate: неполные страницы игр не публикуются. Каждая опубликованная игра должна иметь подтверждённые метаданные, интегрированный текст, 10–20 источников, минимум 6 скриншотов и официальное видео при его наличии.

Подробные обязательные правила: `PROJECT_RULES.md`.
