# Игропоиск

Отдельный репозиторий проекта «Игропоиск».

## Канонические документы проекта

- **ПУТЬ / roadmap:** `docs/PROJECT_ROADMAP.md` — что строим, в каком порядке и когда переходим к серверной архитектуре.
- **Архитектура:** `docs/SYSTEM_ARCHITECTURE.md` — как связаны модули, страницы, данные, storage, publication, workers и AI.
- **Обязательные правила продукта:** `PROJECT_RULES.md`.

`docs/PROJECT_ROADMAP.md` и `docs/SYSTEM_ARCHITECTURE.md` защищены CI-контрактом: их случайное удаление, переименование, обнуление или потеря этих ссылок блокирует staging/production gate.

Публичный каталог использует строгий publish gate: неполные страницы игр не публикуются. Каждая опубликованная игра должна иметь подтверждённые метаданные, интегрированный текст, 10–20 источников, минимум 6 скриншотов и официальное видео при его наличии.
