# Игропоиск

Отдельный репозиторий проекта «Игропоиск».

## Канонические документы проекта

- **ПУТЬ / roadmap:** `docs/PROJECT_ROADMAP.md` — что строим, в каком порядке и когда переходим к серверной архитектуре.
- **Архитектура:** `docs/SYSTEM_ARCHITECTURE.md` — как связаны модули, страницы, данные, storage, publication, workers и AI.
- **Обязательные правила продукта:** `PROJECT_RULES.md`.
- **Стабильный автономный модуль новостей:** `docs/NEWS_MODULE_STABLE.md` — зафиксированный READY/STABLE contract; дальнейшие изменения только хирургические.

`docs/PROJECT_ROADMAP.md`, `docs/SYSTEM_ARCHITECTURE.md` и `docs/NEWS_MODULE_STABLE.md` защищены CI-контрактом: их случайное удаление, переименование, обнуление или потеря обязательных архитектурных инвариантов блокирует staging/production gate.

Публичный каталог использует строгий publish gate: неполные страницы игр не публикуются. Служебный `game/pending/` для новостных хэштегов не является игровой страницей и не добавляется в публичный каталог/Game Registry; он только сообщает «Материал готовится», пока отдельный модуль страниц обрабатывает очередь.
